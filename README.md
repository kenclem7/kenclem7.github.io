# kenclements.com

Personal site.

- `/` redirects to [Ken's LinkedIn profile](https://www.linkedin.com/in/kenclements/)
- `/weather1/` is a personal 10-day forecast page (Wunderground-style charts, ECMWF + HRRR data via [Open-Meteo](https://open-meteo.com/), non-commercial use with attribution); `/weather/` redirects there
- `/weather2/` shows a city's average year (10-year daily temperature and precipitation averages, ERA5 via Open-Meteo)

Hosted on GitHub Pages.
